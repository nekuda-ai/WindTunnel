WindTunnel benchmark run

2026-09-07 · 8 sites · 11 methods · 3 attempts per task

WindTunnel measures how reliably and cheaply an AI browser agent can operate real websites, comparing four ways it can “see” and act on a page. This run put 11 methods through 49 tasks across 8 sites, 3 attempts each — 2,793 agent runs in total, about $281.35. The four interfaces: WebMCP (the site hands the agent direct tools), computer use (the agent reads screenshots), page structure (the agent reads the DOM / accessibility tree), and code execution (the agent writes Playwright code against the page).

Headline: WebMCP passed 99.6% of attempts (vs 84%–100% for the other interfaces) while being 3×–13× cheaper, 2×–11× lighter (median tokens), and 2×–4× faster.
