WindTunnel benchmark run

2026-08-20 · 8 sites · 10 methods · 3 attempts per task

WindTunnel measures how reliably and cheaply an AI browser agent can operate real websites, comparing three ways it can “see” and act on a page. This run put 10 methods through 49 tasks across 8 sites, 3 attempts each — 2,352 agent runs in total, about $175.62. The three interfaces: WebMCP (the site hands the agent direct tools), computer use (the agent reads screenshots), and page structure (the agent reads the DOM / accessibility tree).

Headline: WebMCP solved 97% of attempts (vs 84%–94% for the other interfaces) while being 3×–11× cheaper, 4×–13× lighter (median tokens), and 3×–4× faster.

A page-reading agent re-reads the whole page on every step, so its cost and token disadvantage compounds with journey length; a WebMCP call returns a small JSON result regardless of how long the journey is. On the longest journeys the cost gap reaches an order of magnitude, while the speed gap — bounded by model latency per turn rather than by payload size — grows more slowly.
